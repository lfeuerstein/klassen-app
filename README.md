# Klassen-App

Sitzplan je Klasse und Schnellbewertung der Projektkompetenz im Unterricht, gedacht für das iPad.

- Gesicht antippen, je Kriterium ++ bis −− geben, Bemerkungen notieren; alles wird mit Datum und Uhrzeit protokolliert.
- Sitzplan per Ziehen anlegen, Fotos mit der Kamera aufnehmen und zuschneiden.
- Teilnehmerliste als CSV aus Moodle einlesen, Ergebnis als CSV für „Bewertungen → Import“ in Moodle ausgeben.

## Datenschutz

**Alle Daten bleiben auf dem Gerät** (Speicher des Browsers bzw. der Home-Bildschirm-App). Die App sendet nichts,
lädt nichts nach außer ihren eigenen Programmdateien und benutzt keine fremden Dienste.
Dieses Repository enthält nur das Programm – nie Namen, Fotos, Noten, Bemerkungen, Exporte oder Sicherungen.

## Auf dem iPad installieren

1. Die Adresse der App in Safari öffnen.
2. „Teilen“ → „Zum Home-Bildschirm“ → „Hinzufügen“.
3. Ab dann über das Symbol starten. Regelmäßig unter „Mehr … → Sicherung speichern“ eine Sicherung in „Dateien“ ablegen:
   Wird das Symbol gelöscht, sind auch die Daten auf dem Gerät weg.
